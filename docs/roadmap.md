# pacecalc ロードマップ

現在地: v0.1（工場試作）— コア変換、完走予測、Riegel予測、CLI、CI。テスト44件。

## Phase 1: 計算コアの拡張
- T004 スプリット表: 目標タイム／ペースから区間ごとの通過タイム表を生成。CLI `splits`、CSV出力対応。
- T005 ヒルクライム物理モデル: パワー・総重量・勾配から登坂タイムを予測し、目標タイムから必要パワーを逆算する。
  - 検証ケース: 富士スバルライン実測（24.03 km、獲得標高 1,211 m、平均 226.6 W、総重量 76 kg → 1:25:35）に対し、明記した前提（CdA、Crr、空気密度）で予測が ±10% に入ることをテストで確認する。
  - モデルの前提と限界（一定勾配近似、無風、一定パワー）は `docs/model.md` に明記する。予測は推定であり実測とは区別する。

## Phase 2: コース対応
- T006 GPX読み込み: コースの距離・標高プロファイルを取り込み、区間ごとの所要時間とパワー配分の計画表を出す。

## 品質方針
- 当面は Python 標準ライブラリのみ。テストは unittest。
